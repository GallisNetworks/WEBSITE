# New rural landscape artwork

Created using the built-in image generation tool for the strategic Gallis Networks draft. Three original fictional locations, not real customer sites. Original output size 1672 × 941. Delivery copies use WebP at quality 87, with no crop or retouching.

Files in this Site:
- dist/images/story/rural-estate.webp
- dist/images/story/connected-property.webp
- dist/images/story/farm-enterprise.webp

The complete final prompt set is in artwork-prompts.json beside this document. Brief: cohesive photoreal architectural aerials of Herefordshire-style fields, farm buildings and rural property; deep greens, charcoal roofs and restrained dusk/lavender tones; no generated logo, typography or HUD. The existing Gallis logo is retained separately.

The story reuses these three new location views across its chapters to show different considerations for a property. All previous stock/close-up imagery has been removed from the story homepage; the detailed draft remains available for comparison. Planning labels and paths are indicative annotations, not measured coverage, coordinates or surveyed infrastructure.
